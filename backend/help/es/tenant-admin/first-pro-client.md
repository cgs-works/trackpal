# Tu primer cliente en TrackPal Pro

Sigue este orden para dejar todo listo sin volver atrás.

## 1. Prepara el Catálogo

Crea el servicio que ofreces y añade al menos un plan.

## 2. Crea el cliente

Completa su nombre, usuario, contraseña y teléfono opcional. Guarda y entrega el nombre de usuario completo que genera TrackPal.

## 3. Crea la suscripción

Desde el cliente abre **Suscripciones**, elige el servicio y plan preparados, añade el correo del servicio y define la duración.

En WhatsApp encontrarás **Clientes**, **Catálogo** y **Suscripciones** dentro del menú de **TrackPal Pro**. Usa `9` para regresar y `0` para cancelar.

Si el último paso falla, el Catálogo y el cliente seguirán guardados. Revisa el dato señalado y vuelve a crear la suscripción.
