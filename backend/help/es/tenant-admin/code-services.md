# Plataformas para buscar códigos

Selecciona los servicios que quieres ofrecer en la búsqueda de códigos de acceso, como Netflix, Disney+ o Spotify.

Abre **Configuración > Plataformas habilitadas**, marca los servicios que usa tu negocio y guarda. Solo aparecerán las plataformas compatibles con TrackPal.

Para que la búsqueda funcione también necesitas WhatsApp vinculado y un buzón central conectado. En WhatsApp, abre **Buscar código de acceso** desde el menú de **TrackPal Starter** o **TrackPal Pro**.

Si no aparece ningún servicio, vuelve a esta sección, comprueba tu selección y guarda otra vez.
