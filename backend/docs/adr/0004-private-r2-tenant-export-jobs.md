# Tenant Data Export uses durable jobs and a dedicated private R2 bucket

Tenant Data Export runs as a durable PostgreSQL-backed background job and stores the resulting ZIP in a dedicated private Cloudflare R2 bucket, separate from the public `trackpal-debug` bucket. A ready object is logically available for 72 hours from `ready_at`; authenticated downloads receive a reusable presigned GET URL valid for 15 minutes, capped so it cannot outlive the object's logical expiry. TrackPal explicitly deletes expired objects and configures R2 lifecycle expiration as a safety net because lifecycle removal is not exact to the second.

Each account has one current export shared between Tenant Admin and Master. A replacement may keep the prior snapshot downloadable until the new upload is ready, then purges it. New generation is limited to once per 24 hours per account, uses a point-in-time data snapshot, retries three times with backoff, and recovers processing leases after 30 minutes. Generation requires the actor's password; downloading an already-ready export requires JWT authorization but no password. Failed job metadata is removed after 72 hours, and ready job metadata is removed with the object at expiry.
