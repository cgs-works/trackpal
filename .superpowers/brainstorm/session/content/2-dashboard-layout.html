Elige la estructura del Layout del Dashboard

¿Cómo organizamos la navegación en los dashboards de Trackpal para la versión 2026?

A

Opción A: Sidebar Lateral Fino (Estilo Linear / Stripe)

Un menú lateral izquierdo que permanece fijo. Contiene el logotipo, selector de organización, enlaces principales (Dashboard, Subscripciones, Catálogo, WhatsApp, Configuración), perfil de usuario en la parte inferior y el toggle de Dark/Light mode. Maximiza el espacio vertical y permite navegar rápidamente entre múltiples pantallas densas.

Ventajas

  • Permite mucha densidad de pantallas (ideal para SaaS complejo)
  • Es el estándar moderno de productividad y herramientas de desarrollo
  • Soporta submenús y secciones plegables muy bien

Contras

  • Ocupa un ancho horizontal fijo (se reduce en móvil a un cajón deslizante)
B

Opción B: Menú Superior (Top-Nav) con Pestañas

Una barra superior horizontal de navegación que contiene el logo, selector de inquilino (tenant) y los enlaces principales como pestañas de texto limpio. El contenido principal utiliza un contenedor centrado (`max-w-7xl` o similar). Muy minimalista y limpio.

Ventajas

  • Se siente increíblemente amplio y centrado en el contenido
  • Muy fácil de adaptar a dispositivos móviles de manera responsive

Contras

  • No escala bien si agregamos más de 5 o 6 secciones principales
  • Menos espacio para acciones rápidas o estados persistentes en pantalla
